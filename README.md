# 📑 Python Piscine - Module 00: Basics & Garden Basics

This module introduces the fundamental concepts of Python, focusing on basic syntax, data types, control flow structures, functions, and an introduction to Type Annotations. The entire theme revolves around managing and automating a virtual garden.

---

## 🛠️ General Requirements
* **Language:** Python 3.10 or higher.
* **Norm:** Code must comply with community style guidelines (PEP 8).
* **Restrictions:** External libraries are forbidden unless specified otherwise.

---

## 🚀 Module Exercises

### 📇 Exercise 0: Hello Garden
* **Objective:** First contact with the standard output in Python.
* **Concepts:** `print()` function, strings, and initial syntax.
* **Files:** `hello_garden.py`
* **Description:** Write a script that displays a personalized welcome message to the 42 garden on the screen.

### 📇 Exercise 1: Garden Name
* **Objective:** Handling variables and user input via the console.
* **Concepts:** `input()` function, string variables, and string formatting (f-strings).
* **Files:** `garden_name.py`
* **Description:** Prompt the user for their garden's name and return a dynamic greeting using the provided input.

### 📇 Exercise 2: Garden Plot Area
* **Objective:** Arithmetic operations and numeric data types.
* **Concepts:** Mathematical operators (`+`, `-`, `*`, `/`), `int`, and `float` types.
* **Files:** `garden_area.py`
* **Description:** Calculate the area of a rectangular garden plot by asking the user for its width and length in meters.

### 📇 Exercise 3: Harvest Total
* **Objective:** List manipulation and accumulators.
* **Concepts:** Lists (`list`), `for` loops, indexing, and built-in functions like `sum()`.
* **Files:** `harvest_total.py`
* **Description:** Given a list of kilograms harvested per plant, calculate and display the total accumulated harvest.

### 📇 Exercise 4: Plant Age Check
* **Objective:** Conditional structures.
* **Concepts:** `if`, `elif`, and `else` statements.
* **Files:** `plant_check.py`
* **Description:** Determine if a plant is ready to be harvested based on its age in days entered by the user.

### 📇 Exercise 5: Water Reminder
* **Objective:** Flow control using conditional loops.
* **Concepts:** `while` loop, logical operators, and decrements.
* **Files:** `water_reminder.py`
* **Description:** Create a countdown of days remaining until the next watering. The script triggers a visual alert when the counter reaches zero.

### 📇 Exercise 6: Count to Harvest
* **Objective:** Generating numeric sequences and ranges.
* **Concepts:** `range()` function, nested loops, and iteration control.
* **Files:** `count_to_harvest.py`
* **Description:** Generate a step-by-step visual countdown of the remaining days until the exact mass harvest date.

### 📇 Exercise 7: Seed Inventory with Type Annotations
* **Objective:** Strict typing enforcement and complex data structures.
* **Concepts:** Dictionaries (`dict`), Type Annotations (simulated static typing), and the `typing` standard library.
* **Files:** `seed_inventory.py`
* **Description:** Design a function with explicit type annotations that receives a seed inventory (with stock and type) and validates that the input data matches the expected types.

---

## 💻 How to Run the Scripts

You can test each exercise by running the Python interpreter from your terminal:

```bash
python3 hello_garden.py
python3 garden_name.py
python3 seed_inventory.py
```
