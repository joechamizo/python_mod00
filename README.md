## ⚙️ Reglas Generales
Para superar este módulo y cualquier evaluación en 42, se deben cumplir estrictamente los siguientes criterios:

* **Norminette:** Todo el código debe estar escrito bajo el estándar de código de Python (PEP 8 / `flake8`).
* **Sin trampas:** Cada programa es individual. No copies código, entiende lo que haces.
* **Manejo de errores:** El código no debe crashear (hacer *segfault* o lanzar excepciones sin gestionar) ante entradas inesperadas.
* **Buenas prácticas:** Usa nombres de variables descriptivos y mantén una estructura limpia.
